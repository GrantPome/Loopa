# 🎹 Loopa 更新日志 · 2026-10-16 → 10-17 🚀

这轮更新把**剪辑**和**卡点**两件事直接搬到了时间轴上 ✂️🎯 隔天又顺手把标点功能揉进了工具栏，用起来更顺手了。

---

## 🧭 2026-10-17｜标点好用了一点

- 打点、自动卡点、上 / 下一个标点全部搬到**顶部工具栏常驻快捷按钮**，还实时显示当前标点数量 🔢
- 「标点」下拉挪进同一个分组，用分隔线与其它功能隔开，不再散落在各处
- 标尺**右键菜单统一**，按命中目标给不同选项：
  - 右键标点旗标 → 「重命名 / 删除标点」
  - 右键波形片段 → 「在此处打标点」
  - 右键标尺空白 → 直接打点
- **删除标点必须在菜单里显式点一下**，杜绝右键即删的误操作 🙅

## ✂️ 2026-10-16｜时间轴直接剪辑

不用再跑进编辑区，波形片段上就能干活：

- 片段左右 **6px 边缘**是修剪热区，悬停变左右箭头光标，按住拖拽即可裁剪头部 / 尾部
- 片段上右键弹出菜单：**在播放头处分割 / 再制 / 删除**
- 分割仅在播放头落在片段内部时可用；裁剪长度下限 1/8 拍，且不超过源音频长度

## 🎯 标记点（标点）系统

给时间轴加了「眼睛能看见」的节拍参照：

- 标尺空白处**双击打点**，`M` 键在播放头处打点
- **双击旗标改名**、拖动移位、右键删除
- 支持**上一个 / 下一个标记跳转**，跟着节拍走

## ⚡ 自动卡点

手动打点太累？让它自己听：

- 分析音频波形，采用**能量包络 + 正向差分 onset 检测**，阈值自适应
- 最小间隔 **0.18s**，一次批量生成标记点
- 零依赖实现，不需要引入额外的音频分析库

## 🗑️ 体验修正

- 删除工程前弹出**确认对话框**，明确提示「操作无法撤销」，别再手滑删库 💧
- **旧工程自动兼容**：自动补全缺失的 `markers` 字段，无需手动迁移数据

## 📝 更新日志机制

- 新增规则：**每次上线新功能必须同步补写更新日志**，按日期倒序排列
- 目前日志硬编码在主页「关于」页的 changelog 数组里
