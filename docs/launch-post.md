## 它"接近桌面端"体现在哪

- 🎛 **混音不是玩具**：每轨都有完整通道条——效果器链、三段 EQ、声像、推子、实时电平表，配限幅器防削波，听感像正经混音台，而不是凑数的小滑块。
- 🎹 **编曲够专业**：钢琴卷帘支持绘制 / 拖拽 / 拉伸 / 框选，力度条、量化对齐、移调快捷键齐活，还能跟 MIDI 双向导入导出。
- 🎤 **录音是完整环**：麦克风直接录成音频轨，波形可视化，片段能拆分、裁剪、加淡入淡出——这套操作逻辑跟桌面 DAW 几乎一致。
- 🎺 **音色能自己换**：内置 13 种音色，也支持导入自己的采样拼成独立乐器，作品不用迁就自带的音色。
- 💾 **数据留得住**：一键导出 WAV / 工程文件 / MIDI，本地自动保存历史工程，还有撤销重做。

换句话说，我没有因为它是个网页就砍掉功能，而是尽量把它做得像你桌面上那款软件——**只是它不用安装、不用登录、换台设备也能立刻接着做。**
